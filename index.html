خطوات الإعداد مرة واحدة بس (مجاناً):
  1. روحي console.firebase.google.com وسجّلي دخول بـ Google
  2. اضغطي "Add project" → سمّيه أي اسم → اضغطي Continue
  3. من القائمة الجانبية: Build → Realtime Database → Create Database
  4. اختاري "Start in test mode" ← اضغطي Enable
  5. انسخي الـ URL اللي بيظهر (شكله: https://my-app-default-rtdb.firebaseio.com)
  6. حطيه في الخانة تحت واضغطي اتصل
