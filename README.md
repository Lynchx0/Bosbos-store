# 🎀 Basobosa Store | متجر بسبوسة

**Basobosa** هو متجر إلكتروني مخصص لعرض وبيع القطع الفريدة والأنماط المتميزة. يقوم المتجر على فكرة **"القطعة الواحدة"** — كل منتج متاح منه قطعة واحدة فقط، والحجز للأسبق!

---

## ✨ فكرة المتجر ومميزاته

* **نظام القطعة الواحدة (Unique Stock):** تجربة تسوق قائمة على التميز؛ كل قطعة تُعرض تكون متاحة لعميل واحد فقط (`متاحة` أو `انحجزت خلاص`).
* **تصفح وتصنيفات متنوعة:** تنظيم المنتجات في أقسام مختلفة لتسهيل الوصول (تيشيرتات، بناطيل، جواكت، قمصان، فساتين، أحذية، إكسسوارات).
* **بحث سريع ودقيق:** إمكانية التدوير والبحث برقم كود القطعة (مثل `B-1234`)، اسم المنتج، أو المقاس.
* **حجز فوري:** زر حجز مباشر لكل قطعة متاحة مع توضيح حالة المنتج لحظياً.
* **تصميم عصري وسلس:** واجهة مستخدم بتصميم داكن (Dark Mode) مريح للعين وتصفح سريع ومباشر.
